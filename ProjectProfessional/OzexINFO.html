About the Project

Due to my NDA, I can't disclose any code or provide screenshots from this project. However, I worked as one of the developers helping build the front-end of a mobile app from the ground up for Ozex, a startup — building out several different pages/screens and connecting the front-end to their backend systems as the app came together. As part of a small team, I contributed to the app's UI using React, HTML, and CSS, translating designs into functional, responsive screens and wiring them up to real data through API calls to the backend. Working at an early-stage startup meant helping shape the app's structure early on, rather than slotting into years of existing conventions — a different kind of experience than working within a long-established codebase. This internship was my first real experience working in a professional development environment outside of school projects: collaborating with a small team, building toward a real product with real users, and helping construct features from an early stage of the app's life.

Systems & Contributions

As part of the front-end team, my contributions centered around a few main areas:

  • Front-end/back-end communication — connected the app's UI to backend services, handling API requests and making sure data displayed correctly across different screens
  • Collaborating with the Figma designer — worked closely with the team's graphic designer, translating Figma mockups into functional front-end pages and giving feedback to help refine the UI as it was built
  • Building out app pages — developed multiple screens/pages for the mobile app from design to implementation, following the project's existing component patterns
  • Version control with Git — used Git as part of the team's workflow for tracking changes and collaborating on the codebase alongside other developers
